# Bazalel

A landing page concept for a shared real estate website platform. The page explains the Bazalel idea, previews a personalized agent address, and introduces a design and launch process.

## Preview

Open `index.html` in a modern browser or serve this folder with any static file server. Three.js, GSAP, Google Fonts, and the sample property photography load from CDNs.

## Current scope

This repository contains the public-facing landing page and visual product demo. Individual realtor sub-sites, account management, publishing workflows, and address routing are future platform features; the page presents the product direction rather than implementing those services.
