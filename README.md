# Bazalel

The public Bazalel landing page is in the repository root. Separate client sites live in `invensiones/` and `theblessinghomes/`; each is served from its own route and keeps its navigation separate from the Bazalel landing page.

## Preview

Open `index.html`, `invensiones/index.html`, or `theblessinghomes/index.html` in a modern browser, or serve this folder with a static file server. Google Fonts and sample real estate photography load from CDNs.

## Platform scope

The Bazalel landing page describes the shared-site concept. The `/invensiones/` and `/theblessinghomes/` pages are self-contained client sites; tenant management and automated site provisioning remain future platform work. Inquiry forms prepare a message for the visitor to review before sending.
